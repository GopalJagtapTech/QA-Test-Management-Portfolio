# Login Feature - Test Cases

| Test Case ID | Test Scenario | Test Steps | Expected Result | Status |
|---|---|---|---|---|
| TC_LOGIN_001 | Login with valid credentials | Enter valid username and password and click Login | User should log in successfully | Not Run |
| TC_LOGIN_002 | Login with invalid password | Enter valid username and invalid password and click Login | Error message should be displayed | Not Run |
| TC_LOGIN_003 | Login with blank username | Leave username blank and enter password | Username validation should be displayed | Not Run |
| TC_LOGIN_004 | Login with blank password | Enter username and leave password blank | Password validation should be displayed | Not Run |
| TC_LOGIN_005 | Verify Forgot Password | Click Forgot Password | Password recovery option should be displayed | Not Run |
