# BUG-001: Incorrect Error Message on Login

## Bug Details

- **Bug ID:** BUG-001
- **Title:** Incorrect error message displayed for invalid login credentials
- **Module:** Login
- **Severity:** Medium
- **Priority:** High
- **Environment:** QA
- **Status:** New

## Preconditions

User is on the Login page.

## Steps to Reproduce

1. Open the Login page.
2. Enter a valid username.
3. Enter an invalid password.
4. Click the Login button.

## Expected Result

A clear and appropriate error message should be displayed.

## Actual Result

The application displays an incorrect or unclear error message.

## Test Data

- Username: Valid test username
- Password: Invalid test password
